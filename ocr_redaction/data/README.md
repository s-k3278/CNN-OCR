# Dataset

Extract the supplied IIIT5K archive so that the dataset directory contains:

- `IIIT5K-Word_V3.0/IIIT5K/train/*.png`
- `IIIT5K-Word_V3.0/IIIT5K/test/*.png`
- `traindata.csv`, `testdata.csv`, `trainCharBound.csv`, `testCharBound.csv`

The training scripts accept either the dataset root containing these CSV files or the `IIIT5K-Word_V3.0/IIIT5K` directory.

Do not include the full dataset in the submission ZIP unless explicitly requested.
