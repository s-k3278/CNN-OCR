# CNN-OCR
This is a charecter recognition project, in which the trained model detects the bounding box of a given image, remove the entire area of bounding box, and retuns the image without any texts. as output, it returns the bounding boxes in the json format. The CNN model is trained on a IIIT-K dataset, which contains less than 5000 images data. So the model has lower accuracy.. feel free to make changes to increase it. U can add more data and research paper for refference.. 

But do not use any libraries or any pre-trained model, transfer learning or fine tuning..
